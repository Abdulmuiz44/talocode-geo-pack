# Talocode GEO pack

Copy the files under `docs/` into `github.com/talocode/talocode` `docs/` so they go live on https://talocode.site after Pages rebuild.

Required live URLs:
- https://talocode.site/robots.txt
- https://talocode.site/llms.txt
- https://talocode.site/sitemap.xml
- https://talocode.site/organization.jsonld

The GitHub connector can read `talocode/talocode` but cannot write to the org until Contents write is granted on the organization.
